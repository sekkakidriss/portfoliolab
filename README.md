# PortfolioLab 🚀

> portfolio analysis tool with 3D visualization and intelligent bond calculations


## 🌟 Features

- 📊 **Multi-Asset Support** - Upload unlimited stocks and commodities
- 🎯 **Individual Investment Amounts** - Set precise amounts for each asset
- 🤖 **Smart Bond Calculations** - Automatic volatility and correlation calculations
- 📈 **Professional Metrics** - Sharpe Ratio, VaR, Beta, and more
- 🎨 **3D Visualization** - Interactive particle background with mouse tracking
- 🔒 **100% Private** - All calculations happen in your browser
- 💾 **No Database** - Your data never leaves your device

## 🎯 How to Use

1. **Upload Stock Data** - Drag & drop Excel or CSV files from [DFM](https://www.dfm.ae/)
2. **Upload Commodity Data** - Add CSV files from [Investing.com](https://www.investing.com/commodities/)
3. **Enter Bond Details** - Just coupon rate and maturity (we calculate the rest!)
4. **Set Investment Amounts** - Specify amount for each individual asset
5. **Analyze** - Get comprehensive portfolio analysis in seconds

## 💻 Technologies

- **HTML5** - Structure
- **CSS3** - Futuristic UI with animations
- **JavaScript (ES6+)** - All logic and calculations
- **Three.js** - 3D particle effects
- **Chart.js** - Data visualization
- **SheetJS** - Excel parsing
- **PapaParse** - CSV parsing
